# Tự đánh giá tuần 1

## Đã học

* Khởi tạo Git repo, add, commit theo chuẩn conventional commits (feat, fix, refactor)
* Quản lý branch: tạo, đổi tên, chuyển nhánh
* Sử dụng .gitignore để loại bỏ file không cần thiết
* Push lên GitHub remote, quy trình branch → PR → review → merge
* Làm việc với TypeScript strict mode, CLI todo app

## Vướng mắc

* Xử lý nested Git repo (taskflow-api có .git riêng)

## Tuần sau cần

* Thực hành thêm quy trình review trên GitHub
* Tìm hiểu CI/CD tự động kiểm tra code
