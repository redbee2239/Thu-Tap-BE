# Type-Safe Todo CLI

Project thuc hanh TypeScript strict mode: CLI quan ly todo, luu du lieu vao file JSON bang `fs/promises`.

## Cai dat

```bash
npm install
```

## Kiem tra type

```bash
npm run build
```

## Chay CLI

```bash
npm run todo -- add "Thuc-Tap"
npm run todo -- list
npm run todo -- done 1
npm run todo -- remove 1
```

Du lieu duoc luu tai `data/todos.json`. Neu file chua ton tai, chuong trinh tu tao danh sach rong.

## Chay drills

```bash
npm run drills
```
